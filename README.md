# ⏳ Countdown Timer

A simple and user-friendly **Countdown Timer** application built with **Python (PyQt5)**.
The project provides a graphical user interface to initialize, start, pause, resume, and reset a countdown timer.

---

## ✨ Features
- Set the user-defined countdown time in minutes and seconds.
- Start, pause, and resume the timer directly.
- Reset the timer anytime to its original value.
- Visual dial display for the remaining time.
- Timer completion notification popup.

---

## 📦 Tech Stack
- **Python 3.12**
- **PyQt5** (for UI & timer functionality)
- **QTimer** (for countdown execution)
